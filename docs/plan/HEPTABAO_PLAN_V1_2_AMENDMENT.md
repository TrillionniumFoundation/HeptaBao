# HeptaBao Plan V1.2 Audit Amendment

V1.2 supersedes V1.1 as the current normative execution model while preserving the full Rust/OpenBao-compatible C5 target.

## Closed by the V1.2 package

- Corrects the Work Package count from the stale stated value 258 to the actual catalog value 301.
- Introduces a normative-document manifest and self-resolved canonical project state.
- Separates code integration from qualification, compatibility and operational authority.
- Introduces a common maturity/execution state machine.
- Forbids self-modifying/self-pushing validation workflows.
- Defines executable Work Package contracts, vertical slices, request happens-before, durability, Oracle, evidence trust and threat-model specifications.
- Requires candidate source overrides to be independently bound from direct dependencies.
- Makes repository-controlled and external blockers machine-distinguishable.

## Authority boundary

This amendment creates no qualification, compatibility claim, dependency selection, migration authority, production authority or release authority. Every such flag remains false until separately verified, signed, scoped, current and unrevoked objects exist.
