## Fixed execution and review boundary

The work clock starts at module entry and remains 52 seconds. The final eight seconds of the original 60-second Runtime allocation are reserved for cleanup and receipt publication. Runtime nice remains 5. There are no subprocesses or network calls, no automatic retries, and no timeout extension. The controller uses the existing isolated Homebrew Python 3.14 interpreter. Native metadata is consumed with Python integers from exact raw input bytes; it must not be parsed and reserialized through JavaScript numbers.

`private-inputs/STAGE_PLAN.private.json` describes the exact six input files and create-only remote directory. `private-inputs/RUNTIME_REQUEST.private.json` is the corresponding one-shot native Runtime request. These plans contain private generation bindings and are excluded from the public manifest, including their hashes. File-mode launch omits `stdin` rather than passing null. The parent owns actual staging and execution; none has occurred for this controller.

## Resource correction and its actual tests

The original 33,953-byte unexecuted draft remains byte-for-byte in `mac_formal_kv2_allrows_projection.r1-unexecuted.original.py`. The complete correction is retained as `projection-resource-boundaries-r1-r2.diff`. The correction installs sticky, non-raising handlers for the owned signals before any file or SQLite birth. It registers every returned original descriptor or connection before the first `fstat` or cancellation check. First-observation failure still leaves the original in the registry for cleanup. Every original receives at most one explicit close attempt; an ambiguous close never causes a later numeric descriptor to be closed again. Standard-output duplicates and redirections are counted separately, and cleanup exceptions do not overwrite the original failure.

The actual local tests in `guards-r3` passed eight cases, with no failures, errors or skips. They exercise a real synthetic SQLite database with string, NULL, BLOB and timestamp cells, rejection of a changed frozen protocol source, interruption immediately after file/dup/connection birth, first-fstat failure, an ambiguous close followed by actual numeric descriptor reuse, preservation of a primary exception during private-stdio sync failure, and timer ownership after an immediate failure. The older `guards-r1` and `guards-r2` originals remain intact. These are local controller guards; they are not an actual Mac projection or product validation.

## Required actual closeout

A consumer must bind the authoritative complete, durable Runtime terminal to both the persisted public result and complete final stdout. The result covers all eight projection obligations and the work-phase file, directory, saved-stdio, private-stdio and SQLite connection counts. Final stdout additionally records publication descriptors and the final resource registry after the receipt was fsynced and closed. Acceptance requires all originals retired, no cleanup errors, no pending signal, work and original handles complete before the original 52-second limit, final publication before the original 60-second limit, and the complete final stdout closeout. The private original-resource prefix explicitly excludes its own writer and later publication descriptors; it is not presented as a final all-handles receipt.

The protocol module is used only by exact-hash AST extraction of its small pure generation/projection validators. The full network protocol and `OwnedWire` are not imported or executed. The separately identified network-wire signal/birth gap therefore remains a blocker for future protocol execution, not a reason to claim this isolated projection executes that wire.
