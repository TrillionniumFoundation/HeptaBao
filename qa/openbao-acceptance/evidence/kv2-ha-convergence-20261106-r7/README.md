### 范围限制

这是完整**已声明捕获代际**的保护和恢复证据。它不证明跨数据库同一时刻的原子快照、所有外部写者已冻结、捕获后的凭证仍有效、完整全机秘密来源已盘点，或原设备丢失后的独立恢复。恢复配置保留捕获时的路径投影，未证明应用启动或客户端路由。候选工作副本未在此次独立验证范围内。全部凭证值、私人内容及其派生指纹均留在私有证据中，不随此目录发布。

这些 SQLite 数据不能被称为已迁移的 OpenBao KV2 历史。后续普通 KV2 需要从这份已核验代际提取明确、完整的记录映射；新基线版本必须明确是新版本，不能伪造旧 OpenBao 的历史、时间或删除状态。其余 SQLite 表继续由完整加密恢复包保护。
