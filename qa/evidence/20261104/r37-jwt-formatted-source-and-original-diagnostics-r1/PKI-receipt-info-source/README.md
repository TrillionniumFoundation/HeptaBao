# PKI formatter: one fixed receipt metadata observation

This adapts the previously approved JWT formatter receipt-info journal by nine explicit replacements (ten literal occurrences). The remaining bytes match exactly. It attaches the already closed PKI context and preserves the original 8 KiB pages, 1 MiB payload cap, single-start marker and external-SDK-before-parse discipline. Only the fixed result.public.json metadata is proposed. Metadata values are unobserved; body reads, other nine files, Cargo and product execution remain unauthorized.
