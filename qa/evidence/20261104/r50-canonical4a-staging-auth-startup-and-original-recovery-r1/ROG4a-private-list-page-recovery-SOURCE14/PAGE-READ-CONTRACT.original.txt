Read an accessible Page's current content. Choose one read shape: {page_id}, {page_id,view:'full'}, {page_id,search:['literal']}, {page_id,view:'excerpts',search:['literal']}, {page_id,block_ids:['observed ID']}, or {page_id,include_content:false}. Omit unused selectors and context fields; never send empty selector arrays. metadata.drive_scope identifies where the Page is stored: space means a Space; workspace_private means a user's drive within the workspace identified by owner_workspace_id; personal means a user's drive with no owning workspace. Locate evidence for every requested change before editing. Search each named target; returned matches and neighbors are candidate blocks, not instructions about what to change. If the requested target is missing, expand the read instead of substituting a related block. Batch exact case-sensitive literal search terms to retrieve matching evidence, or use observed block_ids for targeted editing-view refresh. Editing/full return complete blocks in structuredContent.content.blocks with exact id, kind, hash and markdown. Without selectors, editing returns all blocks without duplicated whole-document Markdown or attribution; full retains those fields. Unselected editing content is limited to 128 KiB compact UTF-8 structured JSON, including guidance and metadata. Larger reads return page_read_selection_required with no content: use search, observed block_ids, excerpts or full without selectors. Obtain a successful read including its guidance before editing. Excerpts requires search and returns matched ordinary Markdown in structuredContent.block_excerpts: exact LF-line windows with full-block hashes and explicit completeness. Complete context and instruction blocks remain in content.blocks. Incomplete windows are not replacement Markdown; native patches still require unique old literals across the entire block. Context is positional, not semantic ancestry. Selection coverage is explicit. Use returned block IDs and hashes for edits. When present, structuredContent.content.through_sequence is an optional read guard; when absent, omit sequence arguments and use patch_page with block_id/expected_hash, or edit_page. Retain returned data for subsequent edits and inspect relevant fields; displaying an entire large envelope can truncate it. Successful reads use structuredContent without a duplicate MCP text copy. Optional references includes known MIME type and byte size for up to 128 links in returned Markdown; references_truncated signals more. Use inspect_page_reference for unknown metadata or read_page_reference for contents. With include_content=false, structuredContent.content is null. For meeting_notes Pages, follow meeting_context and read_page_transcript whenever the request depends on meeting context, including implicit requests. Existing native documents remain accessible when new creation is unavailable. For existing executable native artifacts, read_page returns metadata. Use inspect_artifact with page_id to inspect content, or execute_artifact_code to edit it. Use create_presentation for new documents of that type. This tool is part of plugin `Pages`.
