Create a text Page. To create at the top level of a Drive Space, pass space_id and omit parent_page_id. Use parent_page_id only for a real Page ID, never a Space ID; the child inherits its Space. Omit Space and parent IDs for a private Page. For a Plan, send namespace=plans, namespace_properties_schema_version=1, and namespace_properties with a status and optional assignee_account_user_id. Any Page can have a top-level coordinator_dot_id (a stable personal or shared Dot profile ID). Retain the same idempotency_key across retries. Read the selected Space root first when accessible; otherwise read the writable shared parent and pass parent_page_id. For a new Site in a Space, register the Site with Sites first, then create an empty child with its site_project_id, the selected parent_page_id and a retained idempotency_key. Complete attach_site_to_page using the returned metadata.page_id before building. If interrupted, retry with the same Site, Page and key, not replacements. Do not convert the Space root or a document. Use Markdown for inline formatting and links, even inside supported HTML wrappers. Reserve HTML for documented exceptions such as underline and rich table-cell structure. See the write-page catalog (`references/page-content.md#rich-table-cells`) for supported HTML. This tool is part of plugin `Pages`.
