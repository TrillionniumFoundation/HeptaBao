## Planned effects and limits

The only intended new paths are the source-carrier controls and source-carrier root under the fixed desktop base. Input files stay read-only on ROG. Received files use mode 0400 and incoming mode 0500. The parent requires both complete endpoint replies, source-before/after equality, received same-FD hashes and all owned groups empty. Unknown or partial completion retains the original partial root and job evidence.

The parent remains 300 seconds, each endpoint/SSH child 90 seconds, ConnectTimeout 10 seconds, TERM/KILL cleanup 5 + 5 seconds. The proposed inert outer 60 seconds and transfer outer 360 seconds are explicitly new supervision envelopes. No Git, clone, import, compiler, server, provider or production action is part of this stream.

A future local importer must verify the actual received metadata and transport receipt, then independently check the complete source tree and history. This packet grants no future source/runtime qualification and does not change old B01 unknown evidence.
