## New local custody

The importer holds the fixed carrier directory chain and three read-only file descriptors. It verifies same-FD whole hashes and actual name/identity relationships before and after the clone. The raw export and carrier receipts stay unchanged. Expected carrier provenance includes actual complete endpoints, original deadlines and every owned child stopped; a synthetic receipt used by the component tests is explicitly not acceptance evidence.

The new source lives beside the import controls. SOURCE.mkdir therefore creates it exclusively before Git, and a held directory FD proves that Git used the newly owned directory. Cancellation is deferred across every new fd-open/registration interval. Finally closes every recorded input and directory FD, with close errors making the result fail. The process cleanup remains the original receiver contract; this package does not claim that every earlier timeout signal has no later cleanup phase.
