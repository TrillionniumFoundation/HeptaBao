- 两个所属服务进程均以 SIGTERM 退出并被回收，未强杀。发送端 SSH 进程 exit 0，Mac 和 ROG 预备生产边界均保持不变。

## 凭证与执行边界

发送前在同一 SSH 连接内核验目的主机、UID、源码、阶段清单及二进制。两份恢复份额和原根凭证只通过私有 stdin 进入 Linux 内存；Linux 未保存份额文件，控制平面没有取得秘密值。接收程序与导入的 HTTP 模块均直接执行已经核验过的源码字节，避免核验后重新打开源码的时间差。

此处“未分发份额”特指尚未建立生产分散保管；测试确实将两份份额临时送入了 ROG 内存，不能声称秘密从未离开 Mac。

## 明确未覆盖的门槛

归档是 **V5 初始化种子**。本轮没有激活 V6，没有测试 34 MiB 数据集，也没有证明新的统一候选、三物理节点 HA、生产分散保管、客户端切换或 OpenBao 2.7.1 全量替代。两个生产节点目录仍为空。

早期 r1 仅上传公共辅助源码，两次工具传输结果未知；未启动秘密传输或恢复业务。r1 原请求、源码和未知回执保留。r2 使用独立文件名、独立工作目录和新作业键，不覆盖或重放 r1。
