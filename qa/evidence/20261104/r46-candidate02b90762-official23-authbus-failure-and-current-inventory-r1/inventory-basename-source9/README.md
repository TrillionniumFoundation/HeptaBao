# Bounded discovery successor — review only

All original R1 process/search responses remain immutable. R1 returned a bao PID/start/uid candidate but both name searches stopped at 128 results in one QA-named tree. This proposal narrows to basename matches, adds that exact observed tree to the exclusions, and adds one literal systemd directory name-search. No original request is repeated or silently broadened.

The fourth request is network_inspect({host: "pocket4"}), using the actually observed configured alias. It is a public identity cross-check proposal, not a physical-binding claim or authority to deploy. Host/interface/IP fields must be actually returned before comparison with historical pocket4-ts / 192.168.0.9.

The three searches retain the original per-search 4096-entry / 128-result / 1-MiB / 15-second bounds and existing result API. They are serialized, with original ACK IDs only; no restart on unknown. A denied /etc/systemd/system root remains denied, without symlink, privilege, alternate-path or shell fallback. File names, symlink skips, caps and generic basenames left out by this narrower query remain explicit coverage limits. No configuration, environment, token, archive or binary content is included.
