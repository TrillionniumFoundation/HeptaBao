# Native factory concurrency baseline with a local RPC probe

This is an unexecuted, isolated follow-on to the retained r2c account/read timeout. The five helper sources passed syntax-only job 1a1a7f84165-fc05-2d24. No native app-server, provider request, service restart, production plugin deployment, or client traffic switch occurred during syntax validation.

## What changes

The lifecycle helper now probes each real initialized factory lease with the original installed client's thread/loaded/list({limit:1}) call under the same 8-second limit. A fresh private native home must return data=[] and nextCursor=null. The response is not fabricated and is retained privately before its safe summary is added to the public receipt. The source chain in local-rpc-contract.public.json shows the same-version upstream method dispatch, response schema, and in-memory map read. Complete pinned upstream files are included separately. Their relation to the installed binary is the exact advertised version and separately pinned binary digest; source-to-binary build provenance is not established.

The measured condition is **two initialized native RPC channels sharing one writable private credential directory**. The experiment does not provoke credential refresh, a model call, or conflicting credential writes, and it cannot establish that credential overwrites occurred. The inherited singleWriterInvariantPassed field describes the retirement admission invariant; a collected original baseline must keep it false. A successful evidence-collection exit would not qualify the original product.

## Unchanged requirements

Original installed factory, recycler, SDK, command, model configuration, managed1/2 versus unmanaged native4 authority, order 4/2/1, exclusions, and all source pins remain in force. Actual initialized lease acquisition, active-lease and pending-startup overlap, native and wrapper start identities, native credential generation checkpoints, managed2 import through TLS HeptaBao, original SDK selection, server cold restart, complete logical CAS rollback, and exact owned cleanup remain required. Original 440/70/35/10/15/8/5-second bounds are retained. Any unknown native exit, startup settlement, rollback, or cleanup remains a failure. Harness cleanup cannot be counted as normal factory retirement.

Only the new baseline-local-r3 root may be staged. No prior failed fixture is replayed. Live execution requires the already coordinated explicit peer window after normal workspace timing tests and an independent narrow review of the source differences. The paired production factory/recycler candidate remains uninstalled and unqualified.
