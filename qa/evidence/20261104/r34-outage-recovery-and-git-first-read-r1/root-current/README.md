## 本轮恢复中的关键事实

本地执行环境不可用；Git 与远端主机接口仍可用。后续取证使用已经全文审阅的 Git 归档流程：调用前保存精确请求与启动记录，返回后先保存完整原 SDK 并逐字读回，再解析结果。根审阅者不占用 Native 运行通道，总并发仍限制为两个通道。

H2 原作业已经 exit0，摘要报告 H01/H02/H03 通过。完整报告为 465570 字节，本截点根仅核验了原首段 65536 字节，因此尚未授予完整 H2 资格。后续某页调用之前发生一次 Git 归档 UNKNOWN；原错误、422/404 只读响应、原启动记录和控制流边界均保留。新的恢复包及单页继续请求已审阅，旧树没有重建，旧 UNKNOWN 没有被改写为成功。

AuthBus 原失败位于管理器第 76 行的整数检查；具体被拒字段与原字面值没有原始正文可确认。新诊断只查询原标签、固定 plist、公开 ready/候选记录，并从私有日志路径逐字节读取首个 LF 前缀后投影固定公开字段。它不会自行清理注册或启动业务测试。

JWT R2 的独立源码提交是 e3afc157447d35c861f275a761b29da3e42aff8e，唯一父提交 4e808，九处源码变化、十五个新增回归源码。129 件源码包已经保存；格式化、编译和实际测试计数均为零。独立 source 分支只用于精确主机 checkout。官方 2.7.1 JWT ACL 对照的 23 个观察格仍全部没有实际状态结果；Create 与 Update、DELETE、裸 GET 与 LIST 的差异会独立记录。
