## Why this is needed

The preceding original job mac/1a1b39a2fb0-fc05-83ca achieved actual fixed-ps PPID/PGID/effective-UID0 custody, full9 admission/fences, original exit0 and WNOWAIT/group/FD closure. Its controller nevertheless failed with typed_process_row. Its 21402-byte table, hash and offending field were not public or archived; the exact rejected field/value cannot be reconstructed.

The present manager uses the exact same five-field/first-four-isdecimal guard before filtering the requested groups. The preceding public controller uses it before filtering its own ps PID. Thus a non-target row can refuse either caller. That source fact does not identify the observed failing column. The current manager's returned uid field does not grant direct-child custody: the separate fixed-PID PPID/PGID/UID/birth/WNOWAIT protocol remains unchanged.

Apple fixed commit 6bed8737a34dbb54782a18f47dccf933a9967a12, ps/keyword.c lines 74–80, defines UIDFMT as d on Apple and PIDFMT as d; uid maps e_ucred.cr_uid. This supports testing signed lexical forms. It is not an attestation of this installed binary's source build, nor proof that the old refusal contained any negative value.

## Exact changes

The controller has two forward/two inverse hunks: one closed aggregate projection function, a new schema label, and one call after the original fixed command is known closed but before the original table predicate. All other source bytes, including loaded helpers, ownership, two input files, whole/full9 checks, 262144-byte streaming and all closure logic, remain identical.

The projection publishes only total/rejected row counts, seven fixed width buckets, five fixed lexical classes for each of four numeric column positions, per-column rejection counts, and the first rejected row's width/failing column indexes. It publishes no ordinal, token, state text, unrelated PID/UID, raw row/table, or row/table/token hash. The original guard still executes unchanged after projection; a rejected table remains a diagnostic failure. Final input fence success is still not claimed if that guard refuses.

The additional pass reads only already captured memory and is bounded to 8192 rows, with the original remaining-time check per row. There are no new host reads, writes, subprocesses or signals beyond the separately authorized fresh single-ps diagnostic. Its key and slot are new; no old job is replayed.

Journal changes are two forward/two inverse hunks, confined to the fresh slot, exact request pin and observer-key prefix. Request fields change only stdin and the fresh key. Correct typed stdin binding is in CONTRACT.public.json; the helper rejects the obsolete wire stdin_text field.
